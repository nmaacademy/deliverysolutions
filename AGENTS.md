# Rețetar demo

- Aplicație demo pentru comenzi la restaurant: client, bucătărie, curier și administrare.
- Stack: React 19, TypeScript, Vite 6, Tailwind CSS 4, Motion, Supabase, Leaflet în iframe `srcdoc`.
- Comenzi: `npm run dev`, `npm run lint`, `npm run build`, `npm run preview`.
- Nu face commit, push sau deploy fără cererea explicită a utilizatorului.

## Documentație

- Stare curentă: `docs/STATE.md`
- Design și identitate vizuală: `docs/design.md`
- Lucru temporar: `docs/work/`

## Reguli de proiect

- Interfața vizibilă rămâne în limba română.
- Păstrează navigarea și fluxurile existente; schimbările de brand sunt evoluții țintite.
- Rulează `npm run lint` înainte de `npm run build`.
